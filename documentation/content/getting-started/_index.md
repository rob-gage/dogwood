Work through these pages in order to go from a clean machine to a running sample game. If you only need the mental model, jump to core concepts.

1. [Installation](@/getting-started/installation.md) — prepare Rust and graphics support, build Dogwood, and install the `dogwood` command. Skip it if the CLI is already installed.
2. [Your first project](@/getting-started/first-project.md) — create a project and build, run, or open it in the editor.
3. [Core concepts](@/getting-started/core-concepts.md) — (no setup needed) get the short mental model for scenes, cells, actors, and updates.
4. [Template game walkthrough](@/getting-started/template-walkthrough.md) — tour the sample game's scene, materials, actors, and controls.
