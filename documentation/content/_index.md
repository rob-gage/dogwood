Dogwood is a Rust engine for 2D cellular worlds. Its current implementation combines GPU cellular simulation, Rapier rigid bodies, streamed world chunks, egui user interfaces, an editor, and a command-line tool for creating and running projects.

## Crates and subsystems

| Crate or subsystem | Responsibility |
|---|---|
| `engine_host` | Window and GPU setup, input events, and worker pools. |
| `engine_world` | Scenes, materials, actors, chunk streaming, cellular simulation, and collision. |
| `engine_graphics` | Scene rendering and sprites. |
| `engine_user_interface` | egui integration and game UI components. |
| `engine` | Game-facing facade over the engine subsystems. |
| `editor` | Editor built on the `engine` facade, with direct use of `engine_host`. |
| `cli` | Creates template projects and launches builds, games, and the editor. |
| `engine_audio` | Empty crate. |

> **Limitation:** Fluids have [GPU particle simulation](@/internals/simulation/fluids.md) and [raster-based rendering](@/internals/rendering/fluid-pass.md). Gas has no simulation rules. The cellular renderer draws nonempty cells from their stored colors.
